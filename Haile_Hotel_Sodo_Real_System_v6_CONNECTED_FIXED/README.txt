HAILE HOTEL SODO — REAL SYSTEM V1
1. Open index.html = guest menu.
2. Open admin.html = manager dashboard.
3. Add/edit/delete items in the dashboard.
4. Changes are stored locally in the browser and appear in the guest menu on that same browser.

This is the first working system prototype. For the real QR deployment, the next step is cloud database + secure manager login + public hosting. Nutrition values marked — must be filled with verified data from the hotel's recipes.
